# Lexora · 极简主动回忆背词工作台 & 原生 AI 智能学习助手

> **Lexora** 是一款专为深度英语学习者打造的现代化、极简主义全功能单页面（SPA）学习工作台。结合主动回忆（Active Recall）、艾宾浩斯间隔重复算法、自然伴读书房音效与 **原生内嵌的 AI 助学对话引擎**。

---

## ✨ 核心特性

- 🎯 **主动回忆工作台**：支持盲打拼写自测、心算默读校验与快捷键盘交互，彻底告别被动无效刷词。
- 📚 **权威核心离线词库**：内置 4000+ 权威词汇与英/美原生音标音频，支持离线查词与阅读透视。
- 🤖 **原生单页 AI 助学工作台（汲取 STA1N156/AI-Chat 精髓）**：
  - **零跳转同屏切换**：作为系统原生一级视图，同屏平滑切换，无需等待任何外部页面刷新。
  - **全功能多会话管理**：支持多对话管理、长难句结构拆解、考点语法深度剖析、中英口语对话陪练。
  - **安全隔离**：严禁硬编码公用密钥，每位用户使用自己的专属 API Key，数据和额度各自独立。
  - **富文本体验**：支持流式打字输出、Markdown 格式排版、代码块一键复制与会话导出。
- ☁️ **云端自动同步 & 账号体系**：
  - 免复杂验证的标准账号登录，学习记录自动实时同步至云端（支持 Cloudflare Workers / 自建服务器）。
  - 多设备（手机、平板、电脑）进度无缝接力。
- 🎧 **沉浸书房与番茄钟**：温润细雨与深海潮汐高保真白噪音伴读，配合深度专注番茄时钟。
- 📱 **全平台响应式**：原生级 Liquid Glass 质感，完美适配桌面与移动端触控。

## 🚀 快速启动与使用

### 1. 本地直接运行
本项目为纯静态现代 Web 架构，无需任何编译：
```bash
# 使用任意静态服务器启动，例如
npx serve .
# 或
python -m http.server 8080
```
在浏览器中打开 `http://localhost:8080` 即可进入 Lexora。

### 2. 配置个人专属 API Key
进入系统后，点击导航栏 **「设置」** 或在 **「AI 对话」** 顶部点击 **「配置个人密钥」**，填入您自己的 API Key 与接口地址即可开启 AI 学习助教。密钥仅保存在您的本地浏览器中，绝不上泄或与他人混淆。
