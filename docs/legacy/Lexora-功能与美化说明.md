# Lexora 背词与情境阅读

本次版本把“背单词”和“阅读”拆成两个互不干扰的工作区，同时保留手写、键盘拼写和快速浏览三种学习方式。

## 背单词工作区

- 使用 Anki / 墨墨式单词卡片流程：显示中文释义和例句线索，点击“查看答案”翻牌，再进行评级后自动进入下一张。
- 四级评级：`重来 / 忘记`、`模糊 / 稍后`、`认识 / 掌握`、`熟练 / 斩词`。
- 支持快捷键：空格翻牌，数字 `1` 至 `4` 直接评级。
- 保留手写输入：在手写板上书写英文单词，可一键清空。
- 保留拼写输入：切换到“拼写”模式后直接键盘作答。
- 支持“心算”快速浏览模式，适合复习已熟悉词汇。
- 每组目标可选 5 / 10 / 15 / 20 词；完成后显示本组词数和掌握率。
- 词库优先读取本地 `wordbook_cet4.json`，无网络时自动使用内置词条继续学习。
- 每轮背过的单词会记录下来，可在阅读区一键导入。

## 情境阅读工作区

- 阅读区只负责生成和阅读短文，不会把阅读输入框混进背词卡片。
- 可独立设置目标单词、题材、难度和篇幅。
- 生成的短文保存在本地历史书架，可随时切换查看。
- 支持复制、导出，以及点击高亮单词查看词义。
- “一键填入刚刚背过的单词”会把最近一轮学习内容带入阅读输入框。

## 视觉与交互优化

- 学习页采用“主卡片 + 右侧词单”的工作台布局，当前词、已完成词和待学习词一眼可见。
- 翻牌时保留原有动效层，并通过状态切换保证正反面不会同时显示。
- 评级按钮使用不同语义颜色，减少误触；当前卡片和完成状态有明确视觉反馈。
- 发音使用浏览器内置语音合成，不依赖额外音频服务；可用右上角按钮关闭自动朗读。
- 所有设置和学习进度保存在浏览器本地，刷新页面不会丢失。

## 本地运行

直接打开 `index.html` 即可使用；发布构建时运行：

```bash
npm run build
```

构建结果位于 `public/`，词库文件会一并复制到 `public/wordbook_cet4.json`。
